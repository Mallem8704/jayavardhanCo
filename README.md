# Jayavardhan & Co

Responsive Next.js App Router foundation using TypeScript, Tailwind CSS v4 and Lucide icons.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3000. `npm run build` creates a static site in `out/`. Serve that directory with a static host supporting directory indexes and a custom `404.html`. Because this project exports static HTML, use a static server for the production output; `next start` is not the production serving method.

`npm run typecheck` checks TypeScript. Public content is in `lib/content.ts`; implementation plan and route map are in `docs/IMPLEMENTATION.md`; factual review requirements are in `docs/CONTENT-VERIFICATION.md`.

The original website could not be retrieved during the initial audit. Only user-confirmed firm identity and service categories are represented as facts. Contact delivery and analytics are intentionally absent until their real configuration and content handling are agreed.
